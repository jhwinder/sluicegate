Create patching policy

    
Policies created here block unmatched requests. Add or edit rules in order, or generate a policy with no rules to block everything. Generated YAML is a draft and does not change the active policy.

    
Each rule matches the exact ordered server list supplied in a patch request. Other targets or combinations are blocked. The first matching rule wins.
